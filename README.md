# Проект Kursov3HH

## Описание:
Проект выгружает данные о работодателях и вакансиях с сайта hh.ru, создаёт таблицы с полученными данными. 
Также в проекте можно выполнить некоторые запросы и действия с вакансиями.




## Установка:

1. Клонируйте репозиторий:

```
git@github.com:Daria149/Kursov3Hh.git
```

2. Установите зависимости:

```
pip install -r requirements.txt
```

## Использование:
1. Откройте приложение в вашем веб-браузере.
2. Создайте файл database.ini, и вставьте свои данные для создания таблиц:
"
        [postgresql]
        host=
        user=
        password=
        port=
"
3. Запустите проект.
